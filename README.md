# Rapido Ride Data Analysis

Exploratory Data Analysis (EDA) project on Rapido ride data, performed using Python.

## Overview
This project analyzes ride-level data to uncover patterns and insights around Rapido rides — including trends, ride behavior, and key metrics.

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Files
- `chaithanya.RAPIDO.ipynb` — Main analysis notebook
- `rapido_rides_messy.csv` — Raw ride dataset used for analysis
